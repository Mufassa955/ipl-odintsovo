# Как подключить заявки в Telegram за 10 минут

Форма на сайте уже подготовлена: `index.html` (разметка) + `telegram.js` (отправка).
Нужен только токен бота и id чата.

---

## Шаг 1. Создать бота у @BotFather

1. Откройте Telegram, найдите **@BotFather** (официальный бот), нажмите «Старт».
2. Отправьте команду `/newbot`.
3. Придут два вопроса:
   - **Имя бота** (как его видят пользователи) — например `IPL Одинцово`;
   **Имя пользователя** (username) — обязательно на латинице и с цифрой в конце, например `ipl_odintsovo_bot`.
4. BotFather выдаст токен вида:

   ```
   8123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
   ```

   ⚠️ Токен — это пароль. Не публикуйте его в открытых чатах и репозиториях.

---

## Шаг 2. Узнать id чата, куда приходить заявки

Заявки должны приходить **вам**, а не боту. Есть два пути.

### Вариант А. Личный чат с ботом (самый простой)

1. Откройте своего бота и нажмите «Старт» (или просто напишите ему что-нибудь).
2. Откройте в браузере (в этом чате, не в другом):

   ```
   https://api.telegram.org/bot<ТОКЕН>/getUpdates
   ```

3. В ответе найдите поле `chat.id` — это и есть нужный id (обычно число вида `123456789`).

> Если ответ пустой (`{"ok":true,"result":[]}`) — напишите боту ещё одно сообщение и обновите страницу.

### Вариант Б. Группа или канал студии

1. Создайте группу, добавьте туда бота и **дайте ему права администратора** (иначе он не сможет писать).
2. Напишите в группе любое сообщение.
3. В `getUpdates` найдите `chat.id` этой группы (он будет отрицательным, например `-1001234567890`).

---

## Шаг 3. Вписать данные в сайт

Откройте файл `telegram.js` в папке проекта и замените две пустые строки:

```js
var TELEGRAM_BOT_TOKEN = '8123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw';
var TELEGRAM_CHAT_ID = '123456789';
```

Сохраните файл, задеплойте сайт — и заявки приходят в Telegram.

---

## Как это работает и что будет, если что-то пойдёт не так

- Форма отправляет сообщение через `fetch` в Telegram Bot API — без перезагрузки страницы.
- **Если токен не вписан или запрос не прошёл**, форма покажет сообщение об ошибке и предложит написать в WhatsApp/Telegram.
  Сам `mailto:` в атрибуте `action` остаётся запасным вариантом — то есть форма не «падает» никогда.
- Сообщение приходит в таком виде:

  ```
  Новая заявка с сайта IPL в Одинцово

  Имя: Анна
  Телефон: +7 (916) 123-45-67
  Услуга: Тотал Плюс — 8 800 ₽
  Комментарий: первый раз, чувствительная кожа

  Страница: https://mufassa955.github.io/ipl-odintsovo/
  ```

## ⚠️ Безопасность: токен виден в коде страницы

Токен лежит в `telegram.js` — значит, его может посмотреть любой, кто откроет исходный код.
Для формы записи на лендинге это **приемлемый риск**, если:

- бот только **отправляет** сообщения (не принимает команды);
- у бота включён режим приватности (privacy mode) — он не реагирует на сообщения от посторонних;
- в бот не заведены платёжные или административные функции.

Если понадобится серьёзная защита — форму переводят на серверный обработчик
(например, Cloudflare Worker или собственный скрипт на PHP), и токен уезжает с сервера, а не в браузер.

## Проверка после настройки

1. Откройте сайт, заполните форму, нажмите «Отправить заявку».
2. В Telegram должна прийти заявка.
3. Если пришла ошибка — откройте консоль браузера (F12 → Console): там будет код ответа API.
