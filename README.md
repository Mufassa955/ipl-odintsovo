# IPL в Одинцово — лендинг кабинета лазерной эпиляции

Одностраничный сайт кабинета лазерной эпиляции: hero-блок, преимущества,
тарифы, форма записи, FAQ и контакты.

**Стек:** чистый HTML5 + CSS3. Без JavaScript, без фреймворков, без внешних
зависимостей и CDN. Вёрстка адаптивная (проверена на 375px и 1200px).

---

## Возможности

- **Мобильное меню на чистом CSS** (checkbox-хак) — работает без JS
- **Форма записи через `mailto:`** — без сервера и без JavaScript
- **FAQ на нативном `<details>`/`<summary>`** — аккордеон без единой строки скрипта
- **Три тарифа** с выделением популярного
- **Тёмная оливково-золотая тема** на CSS-переменных, адаптируется под тёмную
  системную тему и учитывает `prefers-reduced-motion`
- **SEO-база**: `description`, Open Graph-теги, `favicon.svg`, `robots.txt`, `sitemap.xml`
- **Доступность**: семантическая разметка, `aria-label`, видимый фокус, контрастные
  цвета, alt-тексты

## Локальный запуск

Проект статический — достаточно открыть `index.html` в браузере.

Для проверки в браузере с локального сервера (корректные пути, кэш, dev-инструменты):

```bash
cd ~/Documents/"Проект по умолчанию"
python3 -m http.server 8000
# затем открыть http://127.0.0.1:8000
```

## Инструменты проекта

### Подготовка фотографий для сайта

`tools/photo_prep.py` — утилита на Python: очищает EXIF (включая GPS-координаты),
учитывает ориентацию камеры, уменьшает до нужной ширины, сохраняет JPEG + WebP,
делает превью и печатает отчёт об экономии.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# обработать папку с фото
.venv/bin/python tools/photo_prep.py ./photos --out assets/img --max-width 1600

# отчёт в JSON (для автоматизации)
.venv/bin/python tools/photo_prep.py ./photos --out assets/img --report report.json
```

Поддерживаются JPEG, PNG, WebP, TIFF и HEIC (фото с iPhone).

### Тесты

```bash
.venv/bin/python -m pytest tests/ -q
```

Покрыты: сохранение пропорций, ограничение ширины, создание всех форматов,
удаление EXIF, пропуск не-изображений, отчёт, коды возврата CLI, транслитерация имён,
цветовая коррекция, обрезка кадра.

### Аудит вёрстки

`tools/audit_page.js` — автоматическая проверка страницы на разных ширинах:
горизонтальная прокрутка, элементы за границами, битые изображения и якоря,
alt-атрибуты, размеры для защиты от CLS, мета-теги, доступные имена ссылок,
пустые секции, бесконечные анимации.

```bash
# открыть в браузере с параметром ширины:
open "http://127.0.0.1:8000/_audit.html?w=375"
```

Текущий статус: **0 ошибок и 0 предупреждений** на ширинах 320, 375, 768, 1024 и 1440 px.

### Режим без анимаций

`?static=1` — весь контент виден сразу, без анимаций появления. Нужен для
скриншотов, печати в PDF и автоматической проверки страницы.


## Публикация

Сайт публикуется через **GitHub Pages** (ветка `main`, каталог `/`):

1. Репозиторий: `https://github.com/Mufassa955/ipl-odintsovo`
2. **Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`**
3. Сайт будет доступен по адресу `https://ipl-odintsovo.ru/`

## Как править

- Тексты, блоки, форма — в `index.html`
- Цвета, отступы, брейкпоинты — в начале `style.css` (CSS-переменные в `:root`)

Тема меняется в одном месте:

```css
:root {
  --olive-900: #23291d;  /* основной тёмный */
  --olive-500: #62704f;  /* средний */
  --gold-500:  #b08d4f;  /* акцент */
}
```
